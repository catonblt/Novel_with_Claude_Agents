# Feedback Directory

This directory contains all feedback and assessment reports, primarily from the Beta Reader Agent.

## Structure

### Beta Reader Reports

```
beta-reports/
  chapter-01-beta.md
  chapter-02-beta.md
  [etc.]
  full-manuscript-beta.md
```

### Scene Feedback

```
scene-feedback/
  ch01-scene01-feedback.md
  ch01-scene02-feedback.md
  [etc.]
```

### Revision Feedback

```
revision-feedback/
  revision-1-feedback.md
  revision-2-feedback.md
  [etc.]
```

## Report Templates

### Chapter Beta Report
Each chapter feedback should include:
- Engagement assessment
- Emotional resonance
- Clarity and comprehension
- Character effectiveness
- Pacing evaluation
- Prose quality
- Specific issues flagged
- Specific strengths noted
- Recommendations

### Scene Feedback
Scene-level feedback should include:
- Does it work? (yes/no/partially)
- What works well
- What doesn't work
- Clarity issues
- Emotional landing
- Character voice
- Specific suggestions

### Full Manuscript Beta
Complete manuscript assessment:
- Overall structure effectiveness
- Pacing across whole work
- Character arc completion
- Thematic coherence
- Ending satisfaction
- Comparative analysis
- Major strengths
- Areas needing work
- Priority revision list

## Usage

The Beta Reader Agent generates reports here after reading drafted material. The Story Advocate Agent synthesizes feedback and presents it to you with recommendations.

Keep all feedback—even when issues are resolved—to track the evolution of the manuscript and maintain a record of what was tried and why.

## Feedback Cycle

1. Beta Reader reads material
2. Beta Reader generates report
3. Story Advocate reviews report
4. Story Advocate discusses with team
5. Story Advocate presents to you
6. You provide direction
7. Team creates revision plan
8. Revisions implemented
9. Results documented

Iterate as needed to achieve quality standards.
