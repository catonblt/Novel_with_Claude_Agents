# Story Bible Directory

This directory contains the comprehensive continuity tracking system maintained by the Continuity Editor Agent.

## Core Documents

### Essential Story Bible Files

1. **`master-story-bible.md`** - Complete integrated reference
2. **`characters.md`** - All character details
3. **`timeline-chronological.md`** - Events in story order
4. **`timeline-narrative.md`** - Events in narrative order
5. **`locations.md`** - All settings and places
6. **`objects.md`** - Significant items inventory
7. **`relationships.md`** - Character relationship matrix
8. **`plot-threads.md`** - All plot/subplot tracking
9. **`knowledge-matrix.md`** - Who knows what when
10. **`world-rules.md`** - Established world logic

## Usage

The Continuity Editor Agent maintains these documents throughout the writing process:

- **During Planning**: Establish initial tracking systems
- **During Drafting**: Track all details as they're established
- **During Revision**: Manage changes and ripple effects
- **Final Phase**: Verify complete consistency

## Access

All agents should reference the story bible:
- Prose Stylist: Check established details before writing
- Character Psychologist: Verify character consistency
- Atmosphere Agent: Confirm location details
- Research Agent: Track verified facts
- Architect: Confirm plot thread status

## Maintenance

The Continuity Editor updates the story bible:
- After each scene is drafted
- After each chapter is completed
- After any revisions
- During final consistency audit

Keep this directory current—it's the source of truth for your fictional world.
