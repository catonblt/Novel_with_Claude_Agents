# Planning Directory

This directory contains all planning and development documents for your novel project.

## Structure

Organize your planning materials as follows:

### Vision & Core Documents
- `vision.md` - Core vision, themes, and aesthetic goals
- `premise.md` - Story premise and central dramatic question
- `themes.md` - Detailed thematic exploration

### Structural Documents
- `structure.md` - Overall narrative architecture
- `outline.md` - Detailed chapter-by-chapter outline
- `timeline.md` - Chronological timeline of all events
- `acts.md` - Act structure and major turning points

### Character Development
- `characters/` - Directory for individual character dossiers
  - Use the character-dossier template from `/templates/`
  - One file per major character

### Setting & World
- `settings/` - Directory for location guides
- `world-building.md` - Overall world/setting notes
- `atmosphere.md` - Atmospheric planning

### Research
- `research/` - Directory for research materials
- `research-log.md` - Track research questions and sources
- `fact-sheets/` - Quick reference materials

### Agent Outputs
- `architect-outputs/` - Structure and outline documents
- `research-briefings/` - Research Agent materials
- Store agent-generated planning documents here

## Usage

This directory supports the Development Phase of your novel project. As you work with the agents, save all planning documents here for easy reference throughout the writing process.

Keep this directory organized and up-to-date—it's the foundation for your story bible and the manuscript itself.
